# Lithium Polymer Longevity Modeling

This is the data storage repository for the lithium polymer battery life cycle study run at Georgia Tech between October 2023 and April 2025, and described in the following conference papers:
- _"A longitudinal life cycle study of lithium polymer batteries for AAM"_ - **European Rotorcraft Forum 2025** - Lee Whitcher, Kaleb Patel, Walther Chong, Marilyn Smith
- _"Longevity Modeling of Lithium Polymer Batteries for Advanced Air Mobility"_ - **AIAA SciTech Forum 2027** - Vladimir Nunez Garcia, Lee Whitcher, Marilyn Smith

See the SciTech paper for detailed descriptions of how the 'Intermediate' and 'Final' datasets were computed.

Contact Lee Whitcher via email at leewhitcher@gatech.edu with questions regarding this dataset.
